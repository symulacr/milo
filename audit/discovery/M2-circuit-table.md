## 4. Method notes

- Patterns reused from `local-happy.mjs` (fee-math + `submitCallTxAsync` + timed `watchForTxData`) and `preprod-actions.mjs` `scenarioSteps`.
- Expiry scenarios use short wall-clock deadlines; offsets must leave room for staged deploy (~40s) plus each call (~30s) before the waited deadline. Both `reserve` and `accept` assert `acceptance deadline reached` (`order.compact:126,135`).
- `resolve` uses `approveOrder=false` (disputeMerchant runs in ACCEPTED with no delivery; `resolve(true)` asserts a submitted delivery).
- Lane lock: `flock .locks/local-circuit-sweep.lock` (see run script).
- Fixed local fee only with `MILO_ALLOW_FIXED_LOCAL_FEE=local-disposable-only` and network `undeployed` (fee-math refuses other networks).
